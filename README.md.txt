 TP3 - Projet Individuel Blockchain
 Sujet du projet

Étude et analyse des transactions Bitcoin sur le réseau TestNet4 à l'aide de Wasabi Wallet.
## Présentation du projet
Ce dépôt GitHub est réalisé dans le cadre du travail pratique TP3 du Master FinTech / Blockchain.
Ce projet porte sur l'étude du fonctionnement des portefeuilles Bitcoin et l'analyse des transactions effectuées sur le réseau TestNet4 à l'aide de Wasabi Wallet.

Problématique
Comment fonctionne un transfert de Bitcoin entre deux portefeuilles et comment peut-on vérifier et analyser cette transaction sur la blockchain TestNet4 ?

 Objectifs
- Comprendre le fonctionnement des portefeuilles Bitcoin.
- Étudier la création et la gestion de deux wallets.
- Comprendre le rôle des clés et des adresses Bitcoin.
- Analyser les transactions sur TestNet4.
- Identifier les entrées, les sorties, les frais et les confirmations.
- Comprendre le mécanisme UTXO.

Démarche
Le projet repose sur une manipulation pratique de deux portefeuilles Wasabi Wallet sur le réseau Bitcoin TestNet4, suivie d'une analyse des transactions à l'aide de l'explorateur Mempool.space.

 Résultats
Les résultats seront présentés à travers des captures d'écran, les liens des transactions TestNet4 et une analyse des données observées.
